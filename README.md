# Steps to run the script "webssl-setup.shx" 

* Download the script [Directly on the server] using the [wget] command as shown below.
* wget  https://raw.githubusercontent.com/yathish21/webssl-affine/main/webssl-downloader.shx.gpg
* Decrypt the downloaded file [webssl-downloader.shx.gpb] using following command
* gpg webssl-downloader.shx.gpb [enter password when prompted].
* Now execute the script as shown below.
* bash ./webssl-downloader.shx
